A program that draws a newspaper front page summing up Thursday 19 November 2026 in one image: the first Trump–Xi–Putin trilateral summit in Shenzhen, the Crimea bridge hit again, the world court ruling on the Rohingya case, Anthropic's record $81.3bn IPO debut on Nasdaq, Voyager 1 one light-day out, GTA VI rolling out worldwide, and India–Japan 2+2 talks in Tokyo. `main.ts` (Node 22, standard library only) renders the page with a hand-written PNG encoder and a 5×7 bitmap font, so two runs write byte-identical output with no network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
